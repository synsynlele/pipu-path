# ADR 0005: Discovery evidence before synthesis

- Status: Accepted
- Date: 2026-07-24

Stage 3 begins with versioned first-party assessment evidence. Assessment
attempts and responses are persistent, private, resumable and user-owned.
Submission requires complete evidence and uses optimistic concurrency.

No AI synthesis, score, potential label, Journey recommendation or Human
Potential Profile mutation is permitted in Stage 3.1. A later slice may derive
reviewable signals only when it can retain evidence links, method/version
provenance, uncertainty and user correction.
