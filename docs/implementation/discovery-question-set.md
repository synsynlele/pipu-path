# Discovery question set

Published set: `foundation_discovery`, version 1.

| Section              | Evidence sought                                        | Response forms                 |
| -------------------- | ------------------------------------------------------ | ------------------------------ |
| My Current Reality   | Present focus and desired change                       | Single select, reflection      |
| What Draws Me        | Recurring interests and energising activity            | Multi select, reflection       |
| What Comes Naturally | Repeated requests and natural contribution             | Reflection, multi select       |
| What Has Shaped Me   | Relevant experience without forced disclosure          | Optional sensitive reflection  |
| What Matters to Me   | Values and desired contribution                        | Multi select, reflection       |
| What I Could Build   | A small real-world experiment                          | Reflection, scale              |
| My Readiness         | Current readiness and safe available support/resources | Scale, age-aware single select |

Required prompts must be answered. Optional prompts can be explicitly skipped.
The shaping prompt is sensitive. Youth and adult readiness variants are
mutually exclusive and filtered by the server from the Stage 2 age band.
Unknown age is ineligible until identity state is resolved.
