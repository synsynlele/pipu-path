# The Unbuilt City — play cleanup, 1 November 2026

## Scope

Audit the existing entrance → foundation decisions/builds → enterprise days → crises → sixteen advanced activities → final showcase → optional service practice/shop → Real Quest handoff. Simplify navigation and instructions without replacing challenges, weakening success rules, rewriting saved progress or adding interiors.

## Findings and corrections

| Journey point | Friction                                                                                                          | Correction                                                                                                                              |
| ------------- | ----------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| City menu     | Shop and extra practice preceded the story; all twelve chapters were expanded                                     | One first Continue action with the current chapter; chapter list and optional sections start collapsed                                  |
| Exploration   | City view, service report, district visits, map and decision review looked like equivalent competing destinations | Group under Explore my city; detailed controls disclosed separately; labels distinguish View my city from Service report                |
| Practice      | Building operations, network repairs and sandbox used overlapping build/service wording                           | Label optional operation practice separately from network repair practice and prototype sandbox; explain these do not advance the story |
| Help          | Long mandatory reading; foundation completion described the main city as complete                                 | Three-step core loop, expandable specific instructions, next-step help for all twelve chapters and a separate true story-complete state |
| Settings      | Keep-awake switch closed the menu after each adjustment                                                           | Keep the settings menu open for this in-place action                                                                                    |
| Recovery      | No keyboard menu dismissal; multiple expanded sections created long menus                                         | Escape closes the menu and restores focus; expanding one top-level section closes the others                                            |
| Restart       | Restart icon adjacent to routine audio/help controls                                                              | Move the existing confirmation-protected action into Restart options; clearly explain what it clears                                    |

## Preserved contracts

Mandatory puzzles, failed-plan feedback, different advanced mechanics, chapter celebrations, Builder Credit rules, city development, player-paced Continue, repair/replay, pause/resume, storage consent and account backup remain intact. No difficulty or economy change. No artificial rewards or additional overlays. The shared navigation/help module serves existing and future chapters without creating a second progression engine.

## Verification and limits

The new DOM navigation checks cover default hierarchy, unique controls, disclosure exclusivity, Escape/focus, short guide and accurate help across all twelve chapters. The real-controller runtime checks help during all sixteen advanced activities, final completion, in-place settings and existing full game progression/resume/build/shop/service behavior. Full npm run validate and exact-head GitHub CI gate release. Preview builds are disabled; only the merged production build is intended.

These are source, DOM and 3D-model checks, not a physical-phone play session. Actual touch comfort, perceived pacing, audio loudness and emotional response still need players on representative phones. Do not claim that every ambiguity or repetition is eliminated. No interior expansion in this cleanup: establish whether the simpler existing loop works first.
