# The city remembers choices

29 October 2026. Owner authorises visible, relevant consequences for harmful
choices and improvement through repair. This is an extension of the same city,
not another game, punishment system, personal judgement or real-world record.

Every retained authored choice has one contract. Working choices keep their
existing infrastructure and living-city benefits. Limited choices show an amber
service warning; they do not automatically dirty the city. Failed and unanswered
responses show a relevant warning: waiting work, interrupted service, unsafe
work, access barriers or unfinished work. Physical waste/burning leaves waste
or scorch marks; water/drainage failures leave standing-water marks. No building
is awarded for inaction. All 108 mappings keep existing construction counts.

One deterministic consequence projection reads existing choices. The same
optional device save reconstructs it without a new save field or schema. A new
working choice removes its own previous warning; it does not silently repair
other decisions. Reset clears markers. Invalid choices create no marks. Existing
service links, capacity and tradeoffs remain authoritative; this slice exposes
them rather than inventing a new damage, weather, health or financial simulation.
No additional resource penalty or staged recovery ledger is claimed.

The existing city inspector identifies current problems and lets the player
review the exact retained decision. Choosing the repair control does not grant
a fix. Only keeping a different authored choice changes the city. Choice outcome
and My City detail name the relevant consequence and retain existing tradeoffs.

Rendering adds at most eight static, noncolliding meshes per selected case,
inside existing reserved plots. Geometry is created only on choice change,
reused on subsequent revisions and culled with the existing scene. There is no
new animation loop, particle engine, texture, dependency, backend or XP award.
Reduced motion keeps the same visible outcome. Physical GPU reliability requires
real-device observation; canvas-stub runtime tests do not establish that.

Acceptance: all 108 policy/shape contracts, plot and street clearance, bounded
mesh reuse, working/poor revisions, legacy-save reconstruction, reset/invalid
records, connected service regression and actual inspector-to-review controls.
Full repository validation and one deliberate preview precede production release.
